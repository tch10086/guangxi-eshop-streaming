# 环境部署手册（A 组：广西农产品电商订单）

> 本手册对应实际搭建环境：VMware Workstation 17 + CentOS 7.9 伪分布式，
> 主机名 `master`，固定 IP **192.168.100.100**（VMware NAT 网段 192.168.100.0/24，网关 .2）。

## 一、虚拟机规格

| 项 | 配置 | 说明 |
| --- | --- | --- |
| 操作系统 | CentOS 7.9 x64 Minimal | kickstart 无人值守安装 |
| CPU | 4 核 | 宿主 32 线程，够用 |
| 内存 | **6~8 GB** | 本机实测 6G 可跑通全栈；低于 6G 会出现 YARN 容器被 Kill、SSH 响应变慢 |
| 磁盘 | 60 GB（单文件稀疏） | LVM 自动分区 |
| 网络 | NAT（VMnet8） | 固定 IP 192.168.100.100 |
| 主机名 | master | `/etc/hosts` 已写入映射 |

## 三、一键部署

```bash
# 1. 把安装包传到 /opt/software/
mkdir -p /opt/software
#    Xshell / WinSCP 上传，或 VMware 共享目录

# 2. 把项目代码放到 /opt/project/gx_eshop
mkdir -p /opt/project && cd /opt/project
git clone <你的仓库地址> gx_eshop     # 或直接上传

# 3. 执行安装脚本（约 10~20 分钟）
cd /opt/project/gx_eshop
bash scripts/install_env.sh
```

脚本自动完成：

1. 主机名 / hosts / SELinux 关闭 / 防火墙关闭 / 时间同步
2. **修复 yum 源**（CentOS7 已 EOL，脚本会切阿里云 vault）
3. 安装 JDK 1.8 → `/opt/module/jdk1.8.0_202`
4. 安装 Hadoop 3.3.4 并写好 `core-site/hdfs-site/mapred-site/yarn-site/workers`
5. 安装 MySQL 8，建 `metastore`（Hive 元数据）与 `gx_ec_mysql`（业务库）
6. 安装 Hive 3.1.2，配 MySQL 元数据库，修复 guava 冲突，`schematool` 初始化
7. 安装 Spark 3.3.0，**放入 Kafka 连接器 4 个 jar**，对接 Hive 元数据
8. 安装 Kafka 3.2.1（含 Zookeeper），建 Topic `guangxi-eshop-stream`
9. 安装 Miniconda Python 3.9 + 依赖（kafka-python/flask/pymysql/pandas/sklearn）
10. 启动全部组件、建 Hive 四层表、建 MySQL 业务表、打印验收结果

## 四、启动与停止

```bash
bash scripts/start_all.sh    # ZK → Kafka → HDFS → YARN → Hive Metastore
bash scripts/stop_all.sh     # 反向停止
```

**顺序不能乱**：Zookeeper 没起 Kafka 会连不上；HDFS 没起 Hive 建表会失败；
Hive Metastore 没起 Spark 读 Hive 表会报 `Unable to instantiate`。

## 五、配置项速查

| 文件 | 关键配置 |
| --- | --- |
| `core-site.xml` | `fs.defaultFS=hdfs://master:8020` |
| `hdfs-site.xml` | `dfs.replication=1`，namenode/datanode 数据目录 |
| `yarn-site.xml` | 关闭 `pmem-check` / `vmem-check`（虚拟机内存小） |
| `hive-site.xml` | MySQL 连接串 `useSSL=false&allowPublicKeyRetrieval=true`；`hive.metastore.uris=thrift://master:9083` |
| `spark-env.sh` | `HADOOP_CONF_DIR` 指向 Hadoop 配置目录 |
| `spark-defaults.conf` | `spark.sql.hive.metastore.version=3.1.2` + `jars=path` |
| `server.properties` | `listeners=PLAINTEXT://master:9092`，`zookeeper.connect=master:2181` |

## 六、常见故障

| 现象 | 排查 |
| --- | --- |
| `yum install` 报 `Cannot find a valid baseurl` | CentOS7 已 EOL，换 vault 源或挂 ISO 本地源 |
| `Failed to find data source: kafka` | Spark jars 目录缺 4 个 Kafka 连接器 jar |
| `java.net.ConnectException: master:9092` | Kafka 没起 / `listeners` 写成了 localhost |
| `Table 'metastore.VERSION' doesn't exist` | Hive 元数据没初始化，执行 `schematool -dbType mysql -initSchema` |
| `NoSuchMethodError ... Preconditions.checkArgument` | guava 冲突，用 Hadoop 的 guava-27 替换 Hive 的 guava-19 |
| YARN 容器 `Container killed on request. Exit code is 137` | 内存不足，调小 `spark.driver.memory` 或加大虚拟机内存 |
| 大屏空白 / 显示"连接失败" | Flask 没起、端口不是 5000、MySQL 没数据 |
| 大屏提示 `接口请求失败：http://127.0.0.1:5000/api/eshop_data` | 页面是双击本地 html 打开的（file://），兜底地址指向本机而不是虚拟机 | 改用 `http://<虚拟机IP>:8000/dashboard.html` 访问；或把 `dashboard.html` 顶部 `API_HOST` 改成虚拟机 IP |
| 时间对不上（水印全丢数据） | 虚拟机时间漂移，`ntpdate ntp.aliyun.com` 校准 |
| Kafka 启动报 `node already exists and owner ... does not match current session` | 非正常关机后 ZK 残留 `/brokers/ids/0`：`pkill -f kafka.Kafka` 后重启；仍不行则 `zookeeper-shell.sh master:2181 delete /brokers/ids/0` |
| 重启后大屏打不开 | Flask 与 `http.server 8000` 不是系统服务，需手动启动（见 README 5.2） |
